# Arsip dokumen desain

Dokumen di folder ini ditulis ketika Tickr masih memakai Supabase (login, profil, server). Sejak migrasi offline-first, isinya **tidak lagi menggambarkan kode saat ini**: tidak ada autentikasi, profil, repository remote, maupun `userId`.

Dokumen dipertahankan hanya sebagai riwayat keputusan desain. Untuk kondisi terkini, baca `README.md` di root dan `TICKR_OFFLINE_FIRST_MIGRATION.md`.
